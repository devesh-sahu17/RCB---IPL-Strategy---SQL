
# RCB IPL Strategy Analysis using SQL

## Project Overview
This project analyses Royal Challengers Bangalore (RCB)'s performance in the Indian Premier League (IPL) using SQL. The objective is to evaluate team and player performance, identify strengths and weaknesses, and derive data-driven insights to support strategic decision-making.

## Tools & Technologies
- Database: MySQL
- Language: SQL

## Key Objectives
- Analyse RCB's batting and bowling performance across seasons.
- Evaluate player consistency and individual performance.
- Compare team performance across different venues.
- Analyse home and away performance.
- Understand the impact of toss decisions on match outcomes.
- Identify players suited to specific venues and conditions.
- Develop performance indicators to support team selection and auction strategies.

## SQL Concepts Used
- Joins and subqueries
- Common Table Expressions (CTEs)
- Aggregate functions
- Window functions (RANK, DENSE_RANK, LAG, ROW_NUMBER)
- CASE statements
- Date and string functions
- Views and table creation

## Key Analysis Areas
1. Team Performance: Runs, wickets, wins and season-wise comparisons.
2. Player Analysis: Batting averages, strike rates, bowling performance and consistency.
3. Venue Analysis: Venue-specific player performance and RCB's win-loss record.
4. Match Strategy: Toss impact, home vs away performance and bowling-style effectiveness.
5. Team Building: Identifying consistent performers, all-rounders and potential player selections.

## Project Files
- SQL File: Contains queries for the analysis.
- Project Documentation: Contains the assigned analytical questions.
- Presentation: Summarises the project analysis and findings.

## Conclusion
The project demonstrates how SQL can be used to transform cricket match data into meaningful performance insights and strategic recommendations for team management.
